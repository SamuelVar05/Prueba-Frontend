# Prueba Técnica Front-End

## Autor: Samuel Vargas

Este repositorio contiene la implementación de la landing page solicitada para la prueba técnica de Front-End. Se desarrolló siguiendo el diseño proporcionado, con versiones adaptadas para **mobile** y **desktop**.

## Tecnologías utilizadas
- HTML5
- CSS3 (con **Media Queries** para responsividad)
- Fuentes locales mediante `@font-face` 

## Estructura del proyecto
```
landing-page/
├── index.html       # Página principal de la landing page
├── styles.css       # Estilos principales
├── assets/images/   # Imágenes utilizadas en la landing page
└── fonts/           # Tipografías locales (opcional)
```

## Cómo ejecutar
1. Clonar el repositorio:
```bash
git clone https://github.com/SamuelVar05/Prueba-Frontend.git
```
2. Abrir `index.html` en cualquier navegador web.

## Notas
- La landing page es completamente **responsive** y se adapta a dispositivos móviles y desktop.
- Se respetó fielmente el diseño proporcionado en el brief de la prueba.
- Si se usan fuentes locales, se declararon mediante `@font-face` en `styles.css`.
